# 스토어 등록 정보 (복붙용)

## 앱 이름
2호선 부루마블

## 부제 (iOS Subtitle, 30자)
지하철에서 펼쳐지는 리얼 보드게임

## 짧은 설명 (Play, 80자)
서울 지하철 2호선이 게임판이 된다! 주사위 굴리고 진짜 지하철 타고 이동하는 오프라인 팀 보드게임

## 긴 설명 (공통)

🚇 서울 지하철 2호선이 통째로 게임판이 됩니다!

2호선 부루마블은 친구들과 실제 지하철을 타고 즐기는 오프라인+온라인 하이브리드 보드게임입니다.
홍대입구에서 출발해 주사위를 굴리고, 나온 만큼 진짜 지하철로 이동하고, 역마다 미션을 수행하며 강남역에 먼저 도착하는 팀이 승리합니다.

■ 이렇게 플레이해요
• 방을 만들고 방 코드를 공유하면 준비 끝 — 회원가입 없음
• 주사위를 굴려 나온 수만큼 실제 지하철로 이동
• 역에 도착하면 미션 수행 (인증샷, 노래방, 편의점 미션 등)
• 코인 퀴즈를 풀어 코인을 모으고 상점에서 아이템 구매

■ 아이템 23종의 심리전
• 🐴 페가수스 — 100코인 모으면 강남까지 논스톱 직행!
• 🪂 페가수스 떨어트리기 — 직행 중인 상대를 격추
• 지정·더블·트리플·홀짝 주사위, 저주, 거꾸로...
• 천사카드로 방어하고, 천사카드 찢기로 뚫고
• 자석으로 앞서가는 팀을 끌어오세요

■ 특수 칸
• 🚇 왕십리 — 정확히 도착하면 수인분당선 지름길로 선릉까지 워프
• 🔒 강변 — 감옥! 다른 팀들이 미션을 깰 때까지 대기

■ 실시간 & 푸시
• 모든 팀의 위치·코인·아이템이 실시간 동기화
• 공격받으면 즉시 푸시 알림

동아리 MT, 대학 축제, 워크숍, 친구 모임 — 몸으로 뛰는 리얼 버라이어티를 원한다면 지금 방을 만들어 보세요!

※ 이 게임은 실제 지하철 이동을 포함합니다. 역사·열차 내에서는 게임 행위를 자제하고 안전에 유의하세요.
